# SAS-mock-LRM

Le site permet de simuler la saisie d'un DRM (Dossier de Régulation Médicale) depuis un LRM (Logiciel de Régulation Médicale).

## Recherche contextuelle

Depuis le dossier, il est possible de lancer une recherche contextuelle sur la plateforme numérique du SAS en cliquant sur le bouton [Rechercher sur la plateforme numérique du SAS].
La recherche contextuelle transmet les informations de localisation (adresse du patient) ainsi que la spécialité et l'identifiant du médecin traitant. La récherche de disponibilités est exécutée automatiquement lors de la redirection vers la plateforme.

## Copier-Coller

Depuis le dossier, il est possible de copier les éléments du dossier patient vers le logiciel d'agenda du professionnel de santé auprès duquel sera pris le rendez-vous pour les soins non programmés grâce à l'extension [SAS-copier-coller](https://github.com/ansforge/SAS-copier-coller) disponible pour les navigateurs Firefox et Chrome. Cet outil permet d'éviter la resaisie des données obligatoires dès lors que le LRM et le logiciel de prise de rendez-vous sont deux solutions web.
